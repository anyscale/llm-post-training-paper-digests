Abstract
Most existing agentic reinforcement learning methods assume single-session trajectories, where interaction proceeds within one continuously accumulated context. However, agentic techniques such as
context compaction and subagent forking may produce trajectories spanning multiple sessions, creating
a mismatch between the single-session training assumption and inference-time execution. Therefore,
we introduce Multi-Session Agentic Reinforcement Learning, a more general setting that supports an
arbitrary number of sessions within a trajectory. Under this setting, a widely adopted method is to
broadcast trajectory-level advantages to all sessions, but this does not distinguish contributions from
various sessions or guide session allocation within trajectories. To address this issue, we propose
Mosaic, a multi-session agentic RL method with critic-free hierarchical optimization. At the trajectory
level, it incorporates session-usage signals into advantage estimation. At the session level, it shapes each
session’s advantage according to the estimated marginal contribution. Experiments on BrowseComp
with Qwen3.5-4B show that Mosaic outperforms broadcasting in both context compaction and subagent
forking scenarios while using fewer sessions on average. Further analyses show that our method achieves
improvements in session utility and allocation, which we suggested is a promising target for future
advances in multi-session agentic RL.

1. Introduction
Agentic Reinforcement Learning (Agentic RL; Gao et al., 2025; Jin et al., 2025; Zhang et al., 2025)
trains Large Language Model (LLM) agents (Shinn et al., 2023; Yao et al., 2022) for multi-turn
reasoning, tool use, and interaction with external environments via online rollouts and reward
feedback, yielding broad performance gains. More recently, LLM agents have incorporated advanced
inference techniques, such as context management (Mei et al., 2025; Zhang et al., 2026a) and harness
engineering (Lin et al., 2026; Zhou et al., 2026), enabling agentic workflows to tackle increasingly
complex and long-horizon tasks. However, most agentic RL methods assume a single-session setting,
where each rollout unfolds as a coherent multi-turn trajectory within a continuously accumulated
context and yields a single training segment (Wang et al., 2026; Xu et al., 2026b).
We argue that the single-session setting is not sufficiently general for optimizing LLM agents. For
example, context compaction compresses the execution history to free up context space while rewriting
the prefix that conditions subsequent actions (Lu et al., 2025; Nguyen et al., 2025; Wu et al., 2025),
thereby initiating a new session. Similarly, subagent forking delegates global goal to subagents which
creates branch sessions (Song et al., 2025; Team et al., 2026; Xu et al., 2026d). Those resulting
trajectories no longer satisfy the single-session assumption, creating a mismatch between training
and inference that compromises consistency and limits optimization potential.

To address this gap, we introduce a new setting termed Multi-Session Agentic Reinforcement
Learning, which supports an arbitrary count of sessions and enables agents with diverse inference
mechanisms to be optimized within a unified algorithm. A straightforward way to handle multi-session
rollouts is through broadcasting, whereby a trajectory-level outcome reward or advantage is replicated
to every token across all sessions (Accio-Lab, 2026; Xu et al., 2026a). However, we argue that this
method provides only coarse supervision and offers no explicit control over optimization across
sessions, resulting in poorly targeted learning signals as trajectories span more sessions.
In this work, we propose Mosaic, a multi-session agentic RL method with critic-free hierarchical
optimization. First, session-aware trajectory-level advantage estimation calibrates outcome-based
advantages using within-group rankings of session counts conditioned on task outcomes, encouraging
successful trajectories to solve tasks efficiently while allowing unsuccessful trajectories sufficient
exploration. Its bounded modulation preserves outcome-induced ordering while incorporating sessionusage guidance, thereby widening relative advantage margins for homogeneous-reward groups.
Second, session-level advantage shaping calculates each session’s marginal outcome gain as an
immediate reward, applies group-relative normalization separately by session type, and combines the
resulting shaping signal with the trajectory-level advantage. Overall, the former provides a long-term,
outcome-oriented global signal, while the latter captures short-term local marginal effects. They
together form a hierarchical optimization target for multi-session agentic RL.
To evaluate our method, we conduct experiments on BrowseComp (Wei et al., 2025) and select
Qwen3.5-4B (Qwen Team, 2026) as the base model. Our Mosaic outperforms multiple single-session
and multi-session agentic RL baselines under both context compaction and subagent forking scenarios.
Moreover, Mosaic achieves up to a 10.1% relative improvement in accuracy over the broadcasting
baseline while using fewer sessions per trajectory on average (3.17 → 2.35). Ablation studies further
demonstrate that session-aware trajectory-level advantage estimation and session-level advantage
shaping each contribute to the final performance gains. Our analyses also reveal several key insights:
(1) shaping trajectory-level advantages with session counts increases within-group advantage variance
and improves sample efficiency; (2) different session types exhibit distinct distributions of session-level
marginal gains, which our type-conditioned normalization helps stabilize; (3) effective multi-session
optimization improves session utility and allocation, a pattern that Mosaic strengthens and that
might offer a potential direction for future work.

3. Methodology
In Mosaic, we optimize the performance of multi-session agentic RL through a hierarchical perspective,
incorporating trajectory-level advantage estimation calibrated with session signals (§3.1), as well as
advantage shaping at the finer-grained session level. (§3.2).
3.1. Session-Aware Advantage Estimation
In vanilla GRPO, the advantage is determined solely by the relative outcome rewards within a prompt
group. Under the multi-session setting, however, session-related metrics may provide additional
relative signals for policy optimization. One metric is the number of sessions 𝑁𝑖 in a trajectory 𝜏𝑖 ,
which serves as a proxy for the extent of exploration and structural complexity of 𝜏𝑖 . Nonetheless, 𝑁𝑖
should not be directly treated as a reward. First, its raw scale may not faithfully quantify meaningful
differences in session utilization. Second, the preferred direction of optimization should depend on
task results, avoiding the policy from exploiting session count without improving performance.
Accordingly, from a group-relative perspective, the session-aware trajectory-level advantages of
multi-session rollouts within a prompt group should satisfy the following ordering constraints:

• C1: For successful trajectories, using more sessions incurs a higher execution cost and hence results
in a lower advantage, whereas using fewer sessions should result in a higher advantage.
• C2: For unsuccessful trajectories, using fewer sessions may suggest insufficient exploration or
execution, especially on challenging tasks, and should thus result in a lower advantage. Conversely,
unsuccessful trajectories that conduct more sessions should receive a higher advantage.
• C3: Task outcome reward must remain the dominant signal. When two trajectories have the same
session counts, the trajectory with lower reward should receive a lower advantage. Using more
sessions alone should not allow an unsuccessful trajectory to outrank a successful one.
Together, these constraints encourage the policy to use enough sessions to complete the task, but no
more than necessary, which represents a desirable objective for multi-session agentic RL. Specifically,
we assume a binary final outcome reward 𝑅 𝑖 ∈ {0, 1}, where 1 and 0 represents success and failure,
respectively. For a prompt group containing both successful and unsuccessful rollouts, the trajectorylevel GRPO advantage satisfies:

context before compaction, and its output state is the compressed prefix passed to the next session.
• Subagent session. The main agent delegates subtasks to subagents which start new subagent
sessions. Its input state is the main-agent context at delegation, and its output state is the updated
main-agent context after the returned result has been incorporated.

Benchmark. We evaluate our method on BrowseComp (Wei et al., 2025), a challenging benchmark
consisting of 1,266 questions that require agents to persistently navigate the web and identify hardto-find, entangled information. We select BrowseComp since its high difficulty demands long-horizon
interactions, making it suitable for assessing agents that produce multi-session trajectories.

agent loop. We organize the baselines by inference configuration. Under single-session inference,
we evaluate (1) the initial model without RL training and (2) a model trained with GRPO in the
single-session setting, representing conventional Agentic RL. Under multi-session inference, we
evaluate (3) the single-session GRPO trained model, representing test-time scaling; (4) a model
trained with Broadcasting in the multi-session setting; and (5) a model trained with Mosaic in the
multi-session setting. We evaluate all multi-session configurations under both context compaction and
subagent forking using their respective agent loops; for multi-session training, the same loops are used
to collect rollouts. Finally, since our session-level advantage shaping in §3.2 builds on information
gain, we evaluate (6) a single-session model trained with IGPO (Wang et al., 2026).

4.2. RQ1: Overall Effectiveness of Mosaic
RQ1 asks whether training in the multi-session setting improves agent performance and whether Mosaic

As shown in Table 1, single-session inference has limited effectiveness on BrowseComp. Agentic RL

the multi-session setting. This suggests that multi-session inference capabilities do not readily emerge
through generalization alone. Among methods trained on multi-session trajectories, Broadcasting
improves multi-session inference performance. Mosaic improves it further, outperforming all baselines
in both the compact and subagent scenarios. Figure 3 (a) illustrates the transformative gains from
multi-session inference, multi-session training, and Mosaic.
Figure 4 shows the training dynamics of each method. Mosaic boosts trajectory reward faster than
Broadcasting and reaches a higher level. The number of sessions increases over training for both
methods, but its growth levels off more clearly with Mosaic. This may be partly due to the more
targeted signal provided by its session-aware advantage, which discourages unnecessary increases in
session count. Overall, Mosaic achieves better task performance at lower execution cost.

IGPO, which applies it at the turn level. From Table 1, Mosaic achieves better performance than
IGPO. Moreover, Figure 3 (b) shows that Mosaic substantially reduces the wall-time of computing
marginal gains, enhancing performance while cutting computational cost.

4.3. RQ2: Ablation Study of Mosaic
RQ2 asks whether each component of Mosaic contributes to its overall performance.
Figure 3 (c)(d) presents the ablation results. Relative to Broadcasting, both levels of components in
Mosaic, namely trajectory-level session-aware advantage estimation and session-level advantage
shaping, contribute to the enhanced final performance. Combining the two components yields a
clear additional gain in the compact scenario, but only a modest gain in the subagent scenario. One
possible explanation lies in their session structures: compact trajectories are linear, whereas subagent
trajectories have a nonlinear structure that more closely resembles a directed acyclic graph. In the
latter case, a session may influence multiple succeeding sessions. Its immediate reward, estimated
from marginal gain, may thus differ from its actual contribution to the final outcome.
4.4. RQ3: Mechanistic Analysis of Mosaic
RQ3 asks how the design of Mosaic contributes to the training process.
First, we examine whether session-aware trajectory-level advantage estimation produces the intended
ordering. As shown in Figure 5, within mixed-outcome groups, advantages approximately decrease
with session count for successful trajectories and increase for unsuccessful ones, while successful
trajectories retain higher advantages. In homogeneous-outcome groups, the fallback mechanism
introduces session-dependent variation, providing differentiated learning signals despite identical
outcome rewards. These patterns illustrate how Mosaic leverages session signals to increase the
within-group variance of relative advantages, thus improving sample efficiency during training.
Second, we examine the effect of reward normalization on session-level shaping signals. As shown
in Figure 5, the distributions of raw marginal information gain differ across session types, primarily
because heterogeneous sessions serve distinct functions. Under global normalization, compaction
sessions, whose raw marginal gains have a lower mean, are further downweighted, introducing a
systematic bias against them. In Mosaic, type-conditioned normalization instead centers and rescales
each type separately, enabling both types to receive positive and negative signals relative to their
respective baselines. This reduces type-dependent distributional bias in advantage shaping.

asks a broader question: when multi-session optimization improves task performance, what session-level
behavioral patterns emerge?
Accordingly, we examine session-level behavior along three dimensions: quantity, or whether the count
of sessions increases or decreases; quality, or whether performance improvement is accompanied
by more useful sessions; and allocation, or whether a limited session budget becomes increasingly
concentrated on execution stages with high marginal utility. As shown in Table 2, for Broadcasting,
which does not directly optimize any specific session-aware pattern, all three metrics increase. Under
Mosaic, the number of sessions does not increase further, while both session quality and allocation
improve. These findings indicate that performance gains via multi-session optimization are associated
with improved session utility rather than a monotonic rise in session count. Moreover, despite using
explicit session-aware optimization, Mosaic does not induce a fundamentally altered behavioral
mechanism. Instead, it strengthens the session-allocation patterns that already emerge from naïve
multi-session optimization.
We argue that effective multi-session optimization is accompanied by improvements in session utility
and allocation. It distributes computation more effectively across sessions, encouraging continued
execution when it yields meaningful progress while suppressing low-utility computation. From this
perspective, the central challenge is not how many sessions an agent should use, but how much useful
progress it can derive from the sessions it executes.

5. Discussion: Future Directions for Multi-Session Agentic RL
Infrastructure for reproducible research. Multi-session trajectories tend to arise naturally when
agents tackle complex, long-horizon tasks. Although some existing benchmarks can elicit these
trajectories with reasonable frequency, suitable public training data remain scarce. This gap limits the
scale, sufficiency, and reproducibility of experiments in multi-session agentic RL. Developing open
training datasets and corresponding agentic execution environments is therefore essential to building
a sustainable research ecosystem for this topic.

Cross-session state transfer as a central learning objective. Context compaction and subagent
forking both involve information transfer, but serve different purposes: compaction must preserve
sufficient working state for continued execution; forking must provide the information needed to
complete a subtask; merging must integrate subtask results into a state usable by the main agent. These
operations motivate a shared research question: under a limited context budget, what information
should be carried forward to support subsequent decisions? CompactionRL already jointly optimizes
task execution and context summarization (Li et al., 2026). A unified approach to learning state
transfer across compaction, forking, and merging remains an important direction, alongside systematic
investigation of information loss and error accumulation over repeated transfers.
Asynchronous training for multi-session rollouts. For partial rollout or asynchronous training
settings, multi-session execution can amplify variation in trajectory lengths and completion times,
increase policy staleness and complicate within-group comparisons and sample reuse. For instance,
prioritizing completed rollouts may favor trajectories with less sessions over longer ones associated with
harder tasks, introducing selection bias and shaping learned execution strategies. Our experiments
use a colocated setup with alternating rollout and training phases to minimize interference from
asynchrony and isolate the effects of the optimization signals. Scaling toward actual production raises
a further question: how can multi-session optimization remain reliable under asynchronous sampling
and policy staleness? SAO explores asynchronous optimization with one rollout per prompt, using a
learned value model (Hou et al., 2026). However, critic-free, group-relative optimization requires
further investigation into when and how rollout groups are formed, how stale samples are handled,
and how collected trajectories can be reused.
Toward RL within (black-boxed) agent harnesses. General multi-session agentic RL can accommodate workflows in which execution no longer follows a single, continuously accumulated context
prefix. Context compaction and subagent forking, the two scenarios studied in this work, are representative examples of such workflows in modern agent harnesses. Progress in multi-session optimization
could thus provide an important foundation for training agents within harnesses whose orchestration
is partially opaque (Xu et al., 2026a), such as Claude Code. Therefore, a critical next step is to
systematically examine mechanisms across agent harnesses that disrupt context continuity, such as
dropping reasoning tokens or tool responses, and improve general multi-session agentic RL under
these conditions. Additionally, when discontinuity occurs, the choice between introducing a new
session boundary and applying lossy concatenation with the preceding session may also influence the
overall effectiveness of optimization.

6. Related Work
LLM Agents. LLM agents extend LLMs with tool use and environment interaction to work autonomously (Feng et al., 2026; Li et al., 2025; Wang et al., 2024; Wu et al., 2026). ReAct constructs a
general agent loop of reasoning, acting, observing environment feedback, and continuing until task
completion (Yao et al., 2022). To handle complex and long-horizon tasks, recent systems develop
agent harnesses that manage execution beyond the basic ReAct loop (OpenClaw, 2026; Works, 2026),
incorporating context compaction (Nguyen et al., 2025), multi-agent system (Chen et al., 2026a),
subagent forking (Team et al., 2026), and other forms of context and workflow management (Chen
et al., 2025; Kim et al., 2025; Shi et al., 2026; Xu et al., 2026c; Yang et al., 2026; Zhang et al., 2026a).

Agentic RL. Reinforcement learning techniques such as RLHF (Ouyang et al., 2022; Zhang et al.,
2026b) and RLVR (Chen et al., 2026b; Yu et al., 2026) are used to improve LLMs’ alignment, reasoning,
and downstream task-solving capabilities (Tan et al., 2025; Zheng et al., 2025). Agentic RL extends this
paradigm to LLM agents, aiming to enhance capabilities of multi-turn interaction through enhanced
rollout sampling (Dong et al., 2026; Hou et al., 2025), process-level reward design (Liu et al., 2026;
Zhang et al., 2026c), and other optimization strategies (Deng et al., 2026). However, most existing
agentic RL methods still assume that each trajectory is contained within a single session.

7. Conclusion
In this paper, we first identify a mismatch between the single-session assumption underlying most existing agentic RL methods and advanced agentic inference techniques such as context compaction and
subagent forking. This motivates our formulation of Multi-Session Agentic Reinforcement Learning,
which supports an arbitrary count of sessions within a trajectory. To address the coarse supervision
issue existed in the currently widely used broadcasting approach, we further propose Mosaic, a
multi-session agentic RL method with critic-free hierarchical optimization. By combining sessionaware trajectory-level advantage estimation with session-level advantage shaping, Mosaic trains a
Qwen3.5-4B agent that outperforms both single-session and multi-session baselines on BrowseComp.
Ablation studies confirm the contribution of each component, while further analyses suggest that
effective multi-session optimization might depend on improving session utility and allocation, a
pattern observed in both broadcasting baseline and our Mosaic. We hope these findings will inform
future research on multi-session agentic RL.

successful only if a non-empty <answer>...</answer> block can be extracted. Otherwise, its
session terminates as a failed subagent execution.
For a valid fork call with 𝑞 ∈ {1, 2, 3} assigned tasks, the 𝑞 subagents are launched concurrently. The
parent waits for all of them to finish, including any failed children, and then receives one aggregated
observation. This observation preserves both the task assignment and the completion status of every
child:

The aggregated result is an environment observation and is therefore loss-masked in the main-agent
segment. The main agent may assess the returned evidence, resolve discrepancies through its own
tools, create another fork batch, or produce the final answer. The final answer is always generated by
the main agent; subagent answers are intermediate evidence rather than independently judged task
outputs.
Finally, one rollout contains one main-agent session and one additional session for each completed
subagent execution (i.e., subagent sessions mentioned in §3.2). Thus, if the rollout creates 𝑀
subagents in total, it produces 𝑀 + 1 training segments. Each segment retains its own prompt,
generated tokens, and loss mask. The main-agent segment records the fork calls and the aggregated
subagent observations. Each child segment records only its own search-and-visit trajectory and is
linked to the parent by its fork index.
C.3. LLM-as-Judge
We use an LLM-as-Judge to score each trajectory. If a trajectory produces a final answer in the required
format, we use the following prompt template to compute its trajectory-level reward:
Prompte Template for LLM-as-Judge
You are an expert evaluator. Given a question, a ground truth answer, and a predicted answer,
judge whether the predicted answer correctly and completely matches the ground truth answer
for the question. Accept equivalent wording, aliases, abbreviations, and semantically identical
answers. Reply with only a number: 1 if correct, 0 if incorrect.
Question:{question}
Ground Truth Answer:{ground_truth}
Predicted Answer:{answer}
When multiple ground-truth answers are acceptable, we format them as a list with one ‘- answer‘
entry per line. We set temperature to 0.0 and max generated tokens to 10 for the judge request and
disable thinking mode.
